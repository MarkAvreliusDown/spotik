# Spotik — Spotify Lyrics Translator

Десктоп-клиент поверх Spotify: воспроизведение через Web Playback SDK и построчный
перевод лирики под каждой строкой оригинала.

Требуется **Spotify Premium** (Web Playback SDK не работает с бесплатным аккаунтом).

## Возможности

- Управление воспроизведением прямо из приложения (play/pause/next/prev/seek)
- Синхронизированная лирика (lrclib.net) с автоскроллом к активной строке
- Построчный перевод на выбранный язык — три переключаемых провайдера (настройки →
  «Провайдер перевода»):
  - локальный [Ollama](https://ollama.com) — бесплатно, офлайн, без ключей и лимитов, но
    нужна видеокарта, достаточная для локальной модели;
  - облачный [DeepL](https://www.deepl.com/pro-api) — не требует GPU, есть бесплатный
    тариф с ключом (см. инструкцию ниже). DeepL недоступен в части регионов (HTTP 451
    "Unavailable in your region", в т.ч. для РФ) — в этом случае используйте Yandex
    Translate ниже;
  - облачный [Yandex Translate](https://cloud.yandex.ru/docs/translate/) — не требует
    GPU, работает без VPN из регионов, где заблокирован DeepL, есть бесплатный лимит
    (см. инструкцию ниже)
- Кэш переводов в SQLite — повторный перевод той же строки не бьёт по модели/API

## Установка и запуск (разработка)

Предварительно:

1. [Node.js](https://nodejs.org/) 20+
2. Один из провайдеров перевода (можно несколько сразу и переключаться в настройках):
   - [Ollama](https://ollama.com), запущенный локально, с загруженной моделью:
     ```
     ollama pull gemma2:9b
     ```
   - либо DeepL API-ключ — см. «Получение DeepL API-ключа» ниже (не нужен Ollama и
     видеокарта вообще; недоступен в части регионов, включая РФ)
   - либо ключ Yandex Translate — см. «Получение ключа Yandex Translate» ниже (тоже не
     нужен Ollama/видеокарта, работает из РФ без VPN)
3. `SPOTIFY_CLIENT_ID` и `SPOTIFY_REDIRECT_URI` — см. ниже

### Получение SPOTIFY_CLIENT_ID и SPOTIFY_REDIRECT_URI

Приложение авторизуется в Spotify от имени собственного клиента (OAuth PKCE), поэтому
каждому, кто его запускает, нужно зарегистрировать свой собственный "app" в Spotify —
это бесплатно и занимает пару минут.

1. Откройте [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) и
   войдите под своим Spotify-аккаунтом (нужен тот же Premium-аккаунт, под которым будете
   пользоваться приложением).
2. Нажмите **Create app**.
3. Заполните форму:
   - **App name** / **App description** — что угодно, например `Spotik` /
     `Personal lyrics translator client`.
   - **Redirect URI** — впишите `http://127.0.0.1:43812/callback` и нажмите **Add**.
     Это и есть значение для `SPOTIFY_REDIRECT_URI` — оно должно **дословно совпадать**
     с тем, что указано в `.env` (протокол, хост, порт, путь), иначе Spotify откажет в
     авторизации с ошибкой `INVALID_CLIENT: Invalid redirect URI`. Менять порт `43812`
     не нужно, если только он не занят другим приложением на вашей машине — тогда
     впишите сюда и в `.env` один и тот же свободный порт.
   - Внизу отметьте галочку **Web API** (используется для управления воспроизведением и
     получения профиля/треков) и, поставив согласие с условиями использования, нажмите
     **Save**.
4. Откроется страница созданного app — на ней сразу виден **Client ID**. Это значение
   для `SPOTIFY_CLIENT_ID`. Скопируйте его как есть, без пробелов (client secret не
   нужен — PKCE-флоу его не использует, в клиентском приложении хранить секрет было бы
   небезопасно).
5. Впишите оба значения в `.env` (см. ниже):
   ```
   SPOTIFY_CLIENT_ID=<Client ID из шага 4>
   SPOTIFY_REDIRECT_URI=http://127.0.0.1:43812/callback
   ```

Если позже поменяете `SPOTIFY_REDIRECT_URI` в `.env`, не забудьте продублировать
изменение в **Settings** созданного app на Dashboard (**Edit** → Redirect URIs) — иначе
авторизация будет падать с той же ошибкой `INVALID_CLIENT`.

### Получение DeepL API-ключа (опционально, альтернатива Ollama)

Нужен только если хотите переводить через облако вместо локальной Ollama-модели —
например, если на машине нет видеокарты, достаточной для локального перевода.

1. Откройте https://www.deepl.com/pro-api и нажмите **Sign up for free** (тариф
   **DeepL API Free** — 500 000 символов в месяц бесплатно). Для регистрации попросят
   привязать банковскую карту, но с бесплатного тарифа автоматически ничего не спишут,
   пока вы сами явно не перейдёте на платный план.
2. После подтверждения почты и входа откройте
   [Account → API Keys](https://www.deepl.com/account/summary) — ключ там уже
   сгенерирован, вида `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:fx` (суффикс `:fx` означает
   бесплатный тариф — это часть ключа, не опечатка, копировать нужно целиком).
3. В приложении Spotik: откройте настройки (шестерёнка) → **Провайдер перевода** →
   выберите **DeepL (облако)** → вставьте ключ в появившееся поле → **Сохранить**.
   Статус под полем сменится на «Ключ сохранён».

Ключ хранится в системном хранилище учётных данных (Windows Credential Manager через
`keytar`), а не в файле на диске и не в `.env` — вводится один раз через UI.

### Получение ключа Yandex Translate (опционально, альтернатива DeepL для РФ)

DeepL блокирует запросы из ряда регионов, включая РФ (`HTTP 451 Unavailable in your
region`) — Yandex Translate работает без VPN. Настройка чуть длиннее, чем у DeepL, так
как это Yandex Cloud (нужны и API-ключ, и Folder ID):

1. Зайдите в [Yandex Cloud Console](https://console.cloud.yandex.ru/) под своим
   Yandex-аккаунтом и создайте платёжный аккаунт, если его ещё нет (обычно даётся
   пробный грант — карта нужна для верификации, но с бесплатного лимита Translate API
   автоматически не списывают).
2. Откройте (или создайте) **каталог** (folder) — на странице каталога в Console виден
   его **Folder ID** (строка вида `b1gxxxxxxxxxxxxxxxxx`), скопируйте — это и есть
   `folderId`.
3. В меню слева откройте **Сервисные аккаунты** → **Создать сервисный аккаунт**. Дайте
   любое имя и назначьте роль **`ai.translate.user`** (без неё запросы к Translate API
   будут отклонены с ошибкой доступа).
4. На странице созданного сервисного аккаунта откройте вкладку **API-ключи** → **Создать
   новый ключ**. Ключ показывается только один раз в момент создания — сразу скопируйте
   его целиком.
5. В приложении Spotik: настройки (шестерёнка) → **Провайдер перевода** → выберите
   **Yandex Translate (облако)** → впишите API-ключ из шага 4 и Folder ID из шага 2 в
   появившиеся поля → **Сохранить**. Статус сменится на «Ключ сохранён».

Как и DeepL-ключ, учётные данные Yandex хранятся через `keytar`/OS keychain, не в
файле на диске.

Далее:

```
npm install
cp .env.example .env   # заполнить SPOTIFY_CLIENT_ID своим значением
npm start
```

## Сборка exe

```
npm run dist
```

Соберёт NSIS-инсталлятор и portable-exe в `release/`. Готовые сборки для Windows
также можно скачать со страницы [Releases](../../releases).

Рядом с exe (или с исходным exe для portable-версии) должен лежать файл `.env` —
без него приложение не сможет авторизоваться в Spotify.

## Стек

Electron + TypeScript, Spotify Web Playback SDK + Web API, lrclib.net, перевод через
Ollama (локально), DeepL или Yandex Translate (облако, переключается в настройках),
SQLite (sql.js) для кэша переводов.
